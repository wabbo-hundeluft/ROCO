YOUR WATCH. YOUR CONTEXT.

Know where your health context goes.

Core ROCO scores are calculated locally. Optional AI requests send context to the provider you configure. “Local scores” does not mean that every app feature is offline or that health data can never leave your phone.

The app's data flow

  1. Import: permitted records arrive from the chosen Google Health or Health Connect connection.
  2. Local processing: score calculations, available history, journal patterns and plans are processed on the phone. Persisted app stores use authenticated encryption.
  3. Optional coaching: configured Groq, Mistral, OpenRouter or Gemini services process prompts and attached/permitted personal context. Fallback may try another configured provider.

Your controls

Review health permissions, AI provider settings and personal-context controls before using coaching. API keys and local chat history are stored in app storage; Google access tokens are held in memory. ROCO has no required ROCO cloud account. Deleting or revoking ROCO access does not automatically delete records held by Google or an AI provider.

What can the coach receive?

Depending on configuration and your selected attachments, prompts can include scores, historical summaries, vital signs, workouts, plan details, journal context and chat continuity. The previous user/assistant exchange may be summarized for a follow-up. A provider fallback can transmit that context to another configured service. Check those providers' retention and pricing terms.

This website

This static documentation site adds no analytics, advertising scripts, forms or third-party fonts. It is hosted on GitHub Pages, whose hosting infrastructure can process request information. Images and styles are served from the same website. Visiting external release, source or provider links uses those sites' services. See GitHub's privacy statement.

Safe feedback and security reports

Do not post API keys, tokens, account identifiers or personal health screenshots in public issues. Use the repository's private vulnerability-reporting option if available; otherwise ask for a private reporting channel without disclosing the exploit. Security policy.
