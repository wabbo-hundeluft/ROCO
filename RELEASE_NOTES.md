# ROCO 2.0.20 — choose your language

Early Android preview with in-app language selection.

## New

- Choose System language, Deutsch, English, Français, or Español in Profile → Language.
- Android 13+ uses the native Android app-language setting; older versions persist the choice locally. Unsupported system languages fall back to English.
- Includes the visible morning unfolding sequence, playful robot reactions, new chats with large greetings, and a compact previous-exchange recap across AI providers.

## Installation

Download `ROCO-2.0.20.apk`. App label: **ROCO**. Package: `com.wabbos.healthcoach.v2preview`. Version code: 23. Minimum SDK: 28. This preview is development-signed. Update over the matching ROCO installation to retain local data.
